# Bộ sơ đồ Sequence (PlantUML)

Các sơ đồ dưới đây mô tả luồng xử lý chính của dự án ở phiên bản hiện tại.

- `BaoCao-SEQ-01-Auth-Register-OTP.puml`: Đăng ký tài khoản bằng OTP (tenant).
- `BaoCao-SEQ-02-Auth-Login-ResetPassword.puml`: Đăng nhập, quên mật khẩu và đổi mật khẩu.
- `BaoCao-SEQ-03-Rooms-Management.puml`: Quản lý phòng (xem phòng trống, thêm/sửa/xóa phòng).
- `BaoCao-SEQ-04-Contracts-Rent-Approve.puml`: Thuê phòng và duyệt hợp đồng.
- `BaoCao-SEQ-05-Invoice-Generate-Monthly.puml`: Tạo hóa đơn tháng từ hợp đồng + chỉ số điện nước.
- `BaoCao-SEQ-06-Invoice-Pay-Deposit-Activate.puml`: Thanh toán hóa đơn, kích hoạt hợp đồng sau khi thu cọc.
- `BaoCao-SEQ-07-Utilities-Validation.puml`: Nhập/chỉnh sửa/xóa chỉ số điện nước với các ràng buộc.
- `BaoCao-SEQ-08-Reports-Summary.puml`: Tổng hợp báo cáo dashboard theo kỳ.
- `BaoCao-SEQ-09-Export-PDF.puml`: Xuất PDF hợp đồng/hóa đơn.
- `BaoCao-SEQ-10-Background-Jobs.puml`: Job nền cập nhật quá hạn hóa đơn và hết hạn hợp đồng.

Gợi ý xem nhanh: mở file `.puml` bằng extension PlantUML hoặc dán nội dung lên [PlantUML Web Server](https://www.plantuml.com/plantuml/uml).
